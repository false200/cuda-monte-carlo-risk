Proposed AWS Batch path

Source in aws/ and docker/. Designed in SAM. This Batch stack was not deployed. Live demo is a separate EC2 dashboard VM.

1 · Amazon API Gateway

HTTP API

POST /jobs

GET /jobs/{job_id}

aws/template.yaml

→
invoke

2 · AWS Lambda

python3.12 · handler.py

256 MB · 30 s

validate + write S3 + SubmitJob

does NOT run CUDA

→
put job.txt

3 · Amazon S3

jobs/ prefix

AES256 · 14-day expiry

job.txt + result.json

SubmitJob / DescribeJobs
↓
write result.json
↑

4 · AWS Batch

spot queue

g4dn.xlarge / g5.xlarge

runs same mc_engine on GPU

←
pull image

5 · Amazon ECR

docker/Dockerfile

CUDA image + mc_engine

pulled by Batch workers

↓
launches GPU hosts

6 · Amazon EC2

Batch GPU hosts only

spot g4dn / g5

not the dashboard VM

AWS IAM

Lambda, Batch, and EC2 instance roles

Amazon VPC

subnets + security groups for Batch GPU instances

Correct flow: API Gateway → Lambda → (S3 job files + Batch SubmitJob) → Batch pulls image from ECR → Batch GPU on EC2 writes result.json to S3.
